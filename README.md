此 **Instagram 个人资料数据集样本**包含 **1,556 条记录**，通过 **Bright Data API** 提取。

## 数据点

| 字段名称 | 说明 |
|------------|-------------|
| `account` | Instagram 账户的用户名。 |
| `fbid` | 与 Instagram 账户关联的 Facebook ID。 |
| `id` | Instagram 账户的唯一标识符。 |
| `followers` | 该账户的粉丝数量。 |
| `posts_count` | 该账户发布的帖子总数。 |
| `is_business_account` | 表示该账户是否为企业账户。 |
| `is_professional_account` | 表示该账户是否为专业账户。 |
| `is_verified` | 表示该账户是否已通过 Instagram 认证。 |
| `avg_engagement` | 该账户帖子的平均互动率。 |
| `external_url` | 账户简介中链接的外部 URL。 |
| `biography` | 账户个人资料中的简介部分。 |
| `business_category_name` | 如果该账户是企业账户，则为企业类别名称。 |
| `category_name` | 与个人资料关联的常规类别名称。 |
| `post_hashtags` | 该账户帖子中使用的主题标签。 |
| `following` | 该个人资料关注的账户数量。 |
| `posts` | 该账户所发布帖子的详细信息。 |
| `profile_image_link` | 个人资料图片的 URL 链接。 |
| `profile_url` | Instagram 个人资料的 URL 链接。 |
| `profile_name` | Instagram 个人资料的显示名称。 |
| `highlights_count` | 个人资料中的快拍精选数量。 |
| `highlights` | 个人资料中快拍精选的详细信息。 |
| `full_name` | 账户持有者的全名。 |
| `is_private` | 表示该个人资料是否为私密账户。 |
| `bio_hashtags` | 个人资料简介中的主题标签。 |
| `url` | 个人资料简介部分中的 URL。 |
| `is_joined_recently` | 表示该账户是否为近期创建。 |
| `has_channel` | 表示该账户是否拥有 IGTV 频道。 |
| `partner_id` | 与该账户的业务合作伙伴关联的 ID。 |
| `business_address` | 如果该账户是企业账户，则为企业地址。 |
| `related_accounts` | 与该个人资料相关或相似的账户。 |
| `email_address` | 与该账户关联的电子邮件地址。 |
| `external_url_title` | 外部 URL 的标题或说明。 |


## 使用场景

### 1. 社交媒体影响者分析
通过查看粉丝数量、互动率和内容类别，识别并分析潜在影响者。

### 2. 市场研究与趋势
使用个人资料数据跟踪市场趋势、了解消费者行为并改进产品定位策略。

### 3. 竞争对手基准分析
通过分析竞争对手在 Instagram 上的表现、内容策略和受众互动情况进行基准比较。
