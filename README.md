此 **Instagram 账号资料数据集样本**包含 **1,556 条记录**，通过 **Bright Data API** 提取。

## 数据字段

| 字段名 | 说明 |
|------------|-------------|
| `account` | Instagram 账号的用户名。 |
| `fbid` | 与该 Instagram 账号关联的 Facebook ID。 |
| `id` | Instagram 账号的唯一标识符。 |
| `followers` | 账号的粉丝数。 |
| `posts_count` | 账号发布的帖子总数。 |
| `is_business_account` | 表示该账号是否为企业账号。 |
| `is_professional_account` | 表示该账号是否为专业账号。 |
| `is_verified` | 表示该账号是否已获得 Instagram 认证。 |
| `avg_engagement` | 账号帖子的平均互动率。 |
| `external_url` | 账号简介中链接的外部 URL。 |
| `biography` | 账号资料中的个人简介。 |
| `business_category_name` | 企业账号所属的商业类别名称。 |
| `category_name` | 与该账号资料关联的一般类别名称。 |
| `post_hashtags` | 账号帖子中使用的话题标签。 |
| `following` | 该账号关注的其他账号数量。 |
| `posts` | 账号所发布帖子的详细信息。 |
| `profile_image_link` | 账号头像的 URL。 |
| `profile_url` | Instagram 账号主页的 URL。 |
| `profile_name` | Instagram 账号主页显示的名称。 |
| `highlights_count` | 账号主页上精选快拍的数量。 |
| `highlights` | 账号主页上精选快拍的详细信息。 |
| `full_name` | 账号持有人的全名。 |
| `is_private` | 表示该账号是否为私人账号。 |
| `bio_hashtags` | 账号简介中包含的话题标签。 |
| `url` | 账号简介中的 URL。 |
| `is_joined_recently` | 表示该账号是否于近期创建。 |
| `has_channel` | 表示该账号是否拥有 IGTV 频道。 |
| `partner_id` | 与该账号的商业合作伙伴关联的 ID。 |
| `business_address` | 企业账号的营业地址。 |
| `related_accounts` | 与该账号相关或相似的其他账号。 |
| `email_address` | 与该账号关联的电子邮箱地址。 |
| `external_url_title` | 外部 URL 的标题或说明。 |

## 使用场景

### 1. 社交媒体网红分析
分析粉丝数、互动率和内容类别，识别具有合作潜力的网红及内容创作者。

### 2. 市场研究与趋势分析
利用账号资料数据追踪市场趋势、了解消费者行为，并优化产品定位策略。

### 3. 竞品对标
分析竞品在 Instagram 上的表现、内容策略和受众互动情况，开展竞品对标。
